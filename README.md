# Foyer

Application de dépenses du ménage : partage des dépenses, soldes, budgets, calendrier et lecture de factures.

## Installer sur Android

1. Sur le téléphone, ouvrez ce lien : **[Télécharger Foyer.apk](https://github.com/Themauritian1996/foyer-app/releases/latest/download/Foyer.apk)**
2. Ouvrez le fichier téléchargé.
3. Android demande d'autoriser l'installation depuis cette source : acceptez. C'est normal pour une application hors Play Store.
4. Pour mettre à jour, installez la nouvelle version par-dessus : vos données sont conservées.

## Version web

Sans rien installer : <https://foyer-depenses.web.app>

## Install on Android (English)

1. On your phone, open: **[Download Foyer.apk](https://github.com/Themauritian1996/foyer-app/releases/latest/download/Foyer.apk)**
2. Open the downloaded file and allow installation from this source.
3. In the app: Menu → Réglages → Langue → English.
